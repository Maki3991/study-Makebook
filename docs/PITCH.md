## 一、双叙事系统

我们有两条叙事线，它们是**同一个事实的两种说法**：商业叙事里"信任的来源从平台资本信誉变成规则不可篡改"，就是技术叙事里"合约托管 + 冻结参数 + 确定性清算"。商业线回答"这生意为什么成立"，技术线回答"你凭什么信"。评委从不同的门进来，进到的是同一个房间。

### 商业叙事：这是什么生意

**一句话**：MAKEBOOK 是实体新品的预售交易平台。

**问题**：预售里三方互不信任——消费者先付款怕拿不到货，工厂备料怕订单是假，品牌投产怕反悔。信任需要牌照、资本、历史信誉，所以预售基础设施今天只有大公司运营得起（中国众筹 Top3 平台支持人次占 93.1%，京东众筹 2022 年停运，Drop 独立商城 2026 年 3 月关闭）；中小团队懂品类、有供应链，唯独没有让陌生人先付钱的凭证。

**解法**：让需求先被资金证明，再决定生产。消费者押注愿付价画出真实需求曲线，工厂挂 MOQ 成本曲线竞价，统一清算。

**商业结构**：工厂赚制造的钱（成本价有保障），主理人赚创意的钱（溢价由市场定价），平台赚撮合的钱（成功才收费）。每一方都不碰不属于自己的钱，每一方都只为真实成功付费。

**为什么是现在**：Quirky 烧掉 2 亿美元死了（投票的人不买单），Drop 关了（中心化信任天花板），京东众筹停了——模式全被验证过，缺的都是信任基础设施。

### 技术叙事：凭什么相信你

**一句话（最终版口号）**：**AI 管编译，人管决定，链管钱。**

- **AI 是编译器，不是聊天框**：评论 → 结构化 SKU，每条规格可追溯到评论证据、unknowns 明示、Schema 强校验。AI 没有钱包、没有发布权、不碰一分钱——它只能起草。
- **人是品牌方**：选评论源、逐项编辑确认 SKU（无确认就没有 manifestHash）、定加价公式与保留价、预审工厂、召集社群、承担履约责任（merchant of record）。
- **链是清算层**：愿付价全额托管、工厂报价开盘冻结、十条清算规则任何人可手算、退款与应收全部 pull 支付、合约没有管理员提款函数。
- **Injective 是深思熟虑的选择**：金融向高性能 EVM 让 50 单清算 gas 可忽略（实测 286,858 gas）、MetaMask 零门槛、MTS 是稳定币支付扩展点；我们说得出为什么不用 Exchange Precompile（FBA 清算区块内金融订单，我们清算跨天的实体 MOQ）。
- **证据链**：51 个合约测试、Slither 静态分析、两套真实 testnet Campaign、previewSettlement 链上实测与剧本逐 wei 一致。

### 使用顺序

- **Injective 评委**：技术门进（链当先开场）→ 深聊时放商业的信任门槛论。
- **商业评委 / 媒体**：生意门进（预售平台开场）→ 追问可行性时放"AI 管编译，人管决定，链管钱"与证据链。

## 二、一句话（各版本）

**链当先版（对 Injective 评委）**：
MAKEBOOK 把实体新品的预售变成 Injective 上的公开清算：AI 先把评论区的需求编译成可制造的 SKU 并哈希上链，消费者的愿付价全额托管进合约，工厂 MOQ 报价开盘冻结，截止后合约按公开规则算出统一价——任何人都能手算验证。

**预售当先版（对商业评委 / 大众）**：
MAKEBOOK 是一个实体新品的预售交易平台：消费者用真金白银的愿付价画出需求曲线，工厂挂出 MOQ 成本曲线，截止后由公开合约统一清算——成批就生产，不成就全员退款。

**"选产品"怎么说**：
我们不猜什么产品会火——让愿意先付钱的人，用真金白银把它选出来。（机制版：传统选品靠经验和投票，MAKEBOOK 的选品是一条用全额预锁资金画出来的需求曲线——能清算成功的产品，才配被生产。）

**品牌方怎么说**：
今天演示里的品牌方是我们自己；明天它是任何一个有社群、有创意、但没有大平台入场券的主理人——他们自助发布产品，用我们的清算层，做自己的生意。（边界口径：P0 只有 operator 能创建 Campaign，自助发布是 V1 形态。）

**电梯版（10 秒）**：让需求先被资金证明，再决定生产。

**英文版**：MAKEBOOK turns "I want this" into a funded, on-chain demand curve — factories quote MOQ tiers, and a public contract clears price and quantity at deadline. Production happens only when real money says so.

**节奏技巧**：一句话说完停住，不要自己接着解释——让评委追问，把对话变成他追你。

## 三、评委攻防

### 高频问答

| 问 | 答 |
|---|---|
| 这不就是团购吗？ | 团购是卖家先定价；我们同时收集消费者最高愿付价和工厂 MOQ 成本曲线，截止后按公开规则找可行统一价。 |
| 为什么非用链不可？（进攻型） | 预售里消费者、工厂、品牌三方互不信任，传统解法是平台担保——所以预售基础设施只有大公司运营得起。当规则与资金由公开合约执行，信任的来源从平台资本信誉变成规则不可篡改：运营可信预售市场，不再需要先成为可信的大公司。这是商业结构的改变，不是技术优化。 |
| 为什么一定是 Injective？ | 金融向高性能 EVM、极低 gas（50 单清算 286,858 gas 成本可忽略）、MetaMask 零门槛、Bank/MTS 是稳定币支付扩展点。基础 escrow 可复现，我们不假装它是 Injective 独占。 |
| AI 会不会干掉主理人？ | 干掉"调研与设计执行"，干不掉"召集需求、法律对手方、名声担保"——后者恰是溢价所在。AI 管编译，人管决定。 |
| AI 会不会乱来？ | AI 每条规格都要引用真实评论，人工确认后哈希上链；它没有钱包也没有发布权——能建议，不能动手。 |
| 主理人怎么赚钱？ | 零售差价：品牌应收 = winnerCount ×（零售清算价 − 出厂价 − 平台费），由开盘前冻结的公式分配。清算价即市场发现的品牌溢价。（P0 合约费率为 0、出厂价清算；V1 实现完整三账。） |
| 这不就是 Quirky / 投票众筹吗？ | Quirky 用点赞选拔，点赞的人不掏钱（死因第一条）；我们用全额预锁的资金曲线选拔。它自担制造库存被压死；我们是清算层不碰制造。设计民主化我们学，投票和生产自营不学。 |
| 消费者是在投资吗？ | 不是。条件购买订单：成功得商品，失败退款；无收益、无股权、无二级交易。（语言红线：任何材料永远不说"股东/股权/收益权"。） |

### 众筹经典病灶 × MAKEBOOK 答卷

**机制解决**：虚假需求（表达成本 = 需求本身）；平台改规则（Open 后全冻结，operator 无提款权限）；定价拍脑袋（统一清算价从两边数据长出）；失败退款纠纷（Failed + pull 全额退款）；尾款追收（全额预锁，成功自动成交）。
**设计规避**：MOQ 错配（档位是算法一部分，不可行原子拒绝）；价格歧视纠纷（统一价 + 自动退差额）。
**诚实没解决、答得出路线**：工厂拿钱不生产（里程碑托管定节奏 + 保证金定动机 + 多签/质检做认定——合约分期 trivial，难的是谁告诉合约"生产完了"，预言机问题不假装已解决）；公开出价博弈（签名前披露，V2 commit-reveal）；质量/物流/售后（链保证资金规则，物理世界靠制度四层：KYB / 保证金 / 质检见证 / 声誉）。

### 冠军四点（Injective 赛道）

1. **赛道理解力**：链让一种本来不存在的生意成为可能——不是"把东西搬上链"。还说得出为什么不用 Exchange Precompile。
2. **真实到可以被攻击**：真实 testnet 合约托管资金、算法可手算、51 测试、Slither、双路径现场可重跑、Blockscout 可查。
3. **AI 是承重墙**：AI 管编译、人管决定——AI × Web3 信任问题的标准答案。
4. **诚实的边界感**：TESTNET / DEMO FACTORY / OFF-CHAIN DEMO 全明示；P0/V1 实现状态永不混称。

## 四、三套话术

**30 秒（电梯）**：品牌和工厂都在猜需求——猜错就是库存。MAKEBOOK 是预售交易平台：AI 管编译，人管决定，链管钱。消费者用全额预锁的愿付价画需求曲线，工厂挂 MOQ 报价，Injective 合约按公开规则统一清算——成批生产，不成全退。链让可信预售不再需要一家大公司。

**2 分钟（演示旁白）**：见 `docs/DEMO_RUNBOOK.md` 第 3 节——评论 → AI 候选 → 人工确认 hash → 工厂冻结报价 → 真实钱包下单 → 现场 settle（可请评委亲手触发）→ 差额/全额退款 → Blockscout 验证据。

**5 分钟（评委深聊）**：30 秒版本 → 清算算法手算演示（附录 A 或 A2 数字）→ 进攻型 why-chain（信任门槛论 + 平台集中度数据）→ 主理人经济模型（零售差价、冻结加价公式、保留价）→ Quirky 对照（钱票 vs 点赞）→ 履约四层与分期释放（V2）→ 商业化：成功清算 1–3%（低于行业一半），白标与工厂 SaaS 补规模。
