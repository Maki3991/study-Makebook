# MAKEBOOK Pitch 手册

叙事单一事实来源。30 秒 / 2 分钟 / 5 分钟三套话术 + 评委攻防。演示流程见 `docs/DEMO_RUNBOOK.md`。

## 一句话

**MAKEBOOK 把评论区的"我想要"，变成一条用真金白银预锁的生产需求曲线——消费者押注最高愿付价，工厂挂上 MOQ 成本曲线，Injective 合约在截止时按公开规则一次性清算：成批就生产，不成就全员退款。**

记忆钩子（更短）：**"让需求先被资金证明，再被生产。"**

## 原本的问题（三层断裂）

- **品牌**：看着点赞和评论猜产量，猜错就是库存。
- **消费者**：预售价是卖家单方面定的，"我愿意出多少钱"无处表达。
- **工厂**：收到一堆询价，不知道哪条需求真实，MOQ 阶梯价落不了地。
- **平台**：能收款能显示进度，但清算规则在平台服务器上，随时可以改。

## 我们解决什么

把"口嗨需求"和"真实需求"分开。表达需求的方式是**预锁等于最高愿付价的全额资金**——需求曲线第一次是用钱画出来的。工厂不再对询价报价，而是对已担保的需求曲线报价。清算不由平台、AI 或任何人决定，由所有人都能手算验证的公开算法（R-01~R-10）决定。

## 创新（三件事的组合是新的）

1. **AI 需求编译器**：自然语言评论 → 带证据追溯、明示未知项、Schema 强校验的可制造 SKU；人工确认后哈希上链。AI 无钱包、无资金权限。
2. **全额担保条件订单**：deposit == maxPrice，杜绝廉价虚假需求，清算成功无需追尾款。
3. **生产清算**：消费者愿付价分布 × 工厂 MOQ 成本曲线，统一价、单赢家、确定性 tie-break——清算对象是**未来的生产能力**，不是金融订单。

## 为什么值得 Injective 赛道冠军（按分量排）

1. **赛道理解力**：Injective 作为金融 L1 最想要的叙事是"金融基础设施吃下新的资产类别"，而不是又一个 DEX fork。我们能讲清楚为什么**不用** Exchange Precompile（FBA 清算区块内金融订单；我们是跨数天、含 MOQ 与商品说明书的生产清算）——讲清楚"为什么不用"比硬接 precompile 更证明懂这条链。
2. **真实到可以被攻击**：真实 testnet 合约托管资金、清算算法可手算复现、满负载 settle 实测 286,858 gas、51 个合约测试含余额不变量 fuzz、成功/失败双路径现场可重跑、证据 Blockscout 可查。
3. **AI 是承重墙**：没有 AI，评论→SKU 是昂贵人工研究；有 AI，它是有 Schema、证据链、人工闸门、零资金权限的编译步骤。AI × Web3 的信任问题被权限矩阵干净回答。
4. **诚实的边界感**：TESTNET / DEMO FACTORY / OFF-CHAIN DEMO 标签全部明示，不宣称链能保证物流质量。边界讲得比评委问的还清楚，信任就建立了。

护城河（被问才答）：平台沉淀的是每个品类**用资金画出来的真实愿付价分布数据**——Kickstarter 只有众筹成功数，没人拥有这个价格分布；这是创作者 + 工厂双边网络的飞轮。

## 众筹经典病灶 × MAKEBOOK 答卷

**机制真正解决的**：虚假需求（表达成本 = 需求本身，Sybil 刷量要真金白银）；平台改规则（Open 后 manifest/报价/deadline 冻结，operator 无提款权限，钱只有两条出路）；定价拍脑袋（统一清算价从两边数据长出）；失败退款纠纷（Failed 状态 + pull 全额退款，绕开批量退款 DoS）；尾款追收（全额预锁，成功自动成交退差额）。

**设计上规避的**：MOQ 错配（MOQ 档位是清算算法一部分，不可行原子拒绝）；价格歧视纠纷（统一价 + 自动退差额）。

**诚实没解决、但答得出路线的**：
- **工厂拿钱不生产**——评委必问。三层回答：① 黑客松只用 testnet，无真实损失；② 风险已从"平台+项目方+工厂三方作恶"压缩到只剩工厂履约一个点；③ 路线是**里程碑托管（钱的节奏）+ 工厂保证金（链上可 enforce 的动机）+ 多签/质检预言机（事实认定）**。注意：合约分期放款本身 trivial，难的是"谁告诉合约生产完成了"（预言机问题）；P0 放一个"生产完成"按钮恰恰违背诚实原则。
- **公开出价的策略博弈**——签名前披露，主动取舍；V2 commit-reveal。
- **质量/物流/售后**——链保证资金规则，物理世界靠质检伙伴与合同，列在上主网硬门槛里。

## 高频问答（PRD 19.1 浓缩）

| 问 | 答 |
|---|---|
| 这不就是团购吗？ | 团购是卖家先定价；我们同时收集消费者最高愿付价和工厂 MOQ 成本曲线，截止后按公开规则找可行统一价。 |
| 普通服务器也能做，为什么上链？ | 服务器能改订单、报价、deadline、退款逻辑；这里资金已预锁、输入冻结、结算由公开合约执行。 |
| 为什么一定是 Injective？ | 金融向高性能 EVM、极低 gas（50 单清算 286,858 gas 成本可忽略）、MetaMask 零门槛、Bank/MTS 是稳定币支付的扩展点。基础 escrow 可复现，我们不假装它是 Injective 独占。 |
| AI 会不会造假？ | 可能，所以 AI 无钱包无发布权；每条规格引用评论，人工确认后哈希上链。 |
| 消费者是在投资吗？ | 不是。条件购买订单：成功得商品，失败退款；无收益、无股权、无二级交易。 |

## 三套话术

**30 秒（电梯）**：品牌和工厂都在猜需求——猜错就是库存。MAKEBOOK 让消费者用全额预锁的最高愿付价画需求曲线，工厂挂 MOQ 报价，Injective 合约按公开规则统一清算：成批生产，不成全退。AI 只负责把评论编译成可制造规格，钱全程不由任何人经手。

**2 分钟（演示旁白）**：见 `docs/DEMO_RUNBOOK.md` 第 3 节时间表——评论 → AI 候选 → 人工确认 hash → 工厂冻结报价 → 真实钱包下单 → 现场 settle → 差额/全额退款 → Blockscout 证据。

**5 分钟（评委深聊）**：30 秒版本 → 清算算法手算演示（72 人例或 fixtures 5 人例）→ 为什么不用 Exchange Precompile → 众筹病灶答卷 → 履约三层论（里程碑/保证金/预言机）→ 商业化：成功清算 1–3% 服务费，失败不收费，费率开盘前冻结。
